# 版式写法速查

画布 1600 × 900（16:9）。内容页可用高度约 760 px（标题与页脚之外）。

## 页面类型

| 写法 | 效果 |
|---|---|
| 封面（自动，来自头部） | 图片模式：左上校徽 + 校名，标题左对齐，右半照片渐隐；无图模式：整体居中 |
| `## 目录 {.toc}` | 两列编号卡片，自动列出所有 `#` 分节，可点击跳转 |
| `# 一 部分名` | 分节页：左侧蓝条 + 大号编号，右上校徽，自动“本节内容”导览（列出本节 `##` 标题与状态） |
| `## 标题` | 内容页：眉题（`02 · 节名`）+ 主标题 + 细分隔线 |
| `## 谢谢 {.end}` | 结尾页（校徽在右上；可带分享卡片） |

## 组件

```markdown
## 标题写结论 [✅]{.status}          <!-- ✅ 已完成 / ⏳ 进行中 / 📋 待补 -->

::: {.points}
- 要点卡片；**加粗**深色强调，[关键数字]{.hl} 红色
:::

::: {.stats}
::: {.stat}
[2,822]{.num} 说明文字
:::
::: {.stat .red}
[324]{.num} 红色数字
:::
:::

::: {.key}
结论框（红）
:::
::: {.note}
说明框（蓝）
:::
::: {.todo}
待补框（琥珀）
:::
::: {.refs}
Author, *Journal* 2026.        <!-- 固定在页底的小字 -->
:::
::: {.notes}
演讲者备注
:::
```

## 图文

```markdown
<!-- 左图右文：方图、树图 -->
:::: {.columns}
::: {.column width="58%"}
![](fig/a.png){height="620"}
:::
::: {.column width="42%" .points}
- 要点
:::
::::

<!-- 上图下文：宽图 -->
![](fig/b.svg){height="360" fig-align="center"}

:::: {.columns .points}
::: {.column width="50%"}
- 左栏
:::
::: {.column width="50%"}
- 右栏
:::
::::
```

- 图片自动加白色画框；不要画框：`{height="400" .no-frame}`。
- 线条图优先 SVG（放大不发虚）；照片 / 密集散点用 PNG/JPG。

## 表格

普通 Markdown 表格即可，自动渲染为白底三线表（表头浅蓝）。列多时缩短单元格文字，6 列以上考虑拆表或改图。

## 容量经验（防溢出）

- 纯要点页：≤ 5 条，每条 ≤ 2 行。
- 指标卡 + 要点：指标卡 3–4 个，要点 ≤ 3 条。
- 左图右文：右侧要点 ≤ 4 条。
- 表格：≤ 6 行 × 5 列；再加一个提示框就不要再加别的。
- 代码块：≤ 8 行。
